📊 Анализ успеваемости студентов (C# Course)


      Данный проект предназначен для анализа успеваемости студентов курса «Основы программирования на C#».
      Он включает в себя парсинг данных из CSV-файла, перенос в базу данных SQLite, а также визуализацию
      статистики в виде графиков и Excel-отчётов.


🚀 Основные возможности


       📁 Парсинг CSV – загрузка данных об успеваемости из файла.

       🗄️ Хранение в БД – использование SQLite и ORMLite для работы с сущностями: студент, группа, тема, оценка.

       📈 Графический интерфейс – наглядное отображение:

                    Средних баллов по группам (столбчатая диаграмма);

                    Детализации по студентам кликом по группе;

                    Сортировки студентов по оценкам за ДЗ или упражнения.

      📑 Экспорт в Excel – генерация отчёта со средними баллами по группам и темам, включая встроенную диаграмму.


Используемые технологии


    Java – основной язык разработки

    SQLite – лёгкая реляционная база данных

    ORMLite – объектно-реляционное отображение
    
    JFreeChart – построение графиков

    Apache POI – работа с Excel-файлами
  
    Swing – графический интерфейс пользовател
